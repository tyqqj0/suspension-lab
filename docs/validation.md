# 验证方案（待具体化）

这些检查用于回答“数值／采集／比较是否可信”，不是当前已通过的测试。模型范围与实际平台确认后，在实现前选定测试场景、数值容差与采集持续时间；本文件不伪造一套通用通过阈值。

## A. 物理求解

| 检查 | 方法与应有现象 | 需要固定的条件 |
|---|---|---|
| 静态平衡 | 平路静置后合力／合矩与残余运动在容差内；轮荷之和符合模型总重，弹簧静挠度与独立计算一致 | 质量分解、重力、载荷分配、轮胎模型、等待时间与容差 |
| 自由振动 | 四分之一车的平衡点扰动，与独立方程解的固有频率／衰减比较；整车只在相同简化条件下对照对应模态 | 力律、是否接触、步长、初态、频率／衰减估计方法 |
| 阻尼耗能 | 对被动阻尼验证 `F_d * v_rel <= 0` 的符号和累计耗能；无外部输入时检查模型总能量漂移 | 势能基准、弹簧／轮胎储能、允许的离散误差 |
| 对称性 | 对称车辆／输入不产生非预期侧倾；左右镜像输入产生对应的镜像响应 | 左右参数、输入、初态与符号约定 |
| 作用与反作用 | 检查悬架内部成对施力与施力点，隔离外力后核对动量／力矩账目 | 重力、接触、导向约束的反力不可遗漏 |
| 步长收敛 | 在固定求解器配置下比较 dt、dt/2、dt/4，关键峰值、RMS 与衰减变化应收敛；另查求解器迭代数敏感性 | 目标误差、输入带宽、观测采样方法 |
| 适用范围 | 大位移、轮胎离地、限位等超出当前模型能力时明确告警或标注，不能静默展示为可信 | 当前支持范围与失效判据 |

对照模型是校核手段而非完美真值。接触不连续时按事先选择的误差指标判断，不能只看轨迹截图相似。

## B. 手机采集

- 真机列出型号、系统、软件／浏览器、权限与安装方式；记录目标时长和前台、切导航、锁屏场景。
- 使用原始时间戳统计间隔分布、有效频率、重复／乱序、长间隙及重启后的行为；各流时钟域和跨流对齐方式清楚。
- 静止与受控转动检查轴向、重力、角速度单位和姿态语义；保存处理前后数据，不把估计重力当作直接真值。
- 后台未通过时，显示不可用／中断与实际缺口，不能用插值伪装持续采样。可接受掉帧率和最长间隙由用途先定。
- 首轮连续性测试在安全静止场景完成；路测前确认固定方式、操作安排和不干扰驾驶。

## C. 数据可追溯与往返

- 原始采集在校准、筛选与导出后仍可校验未被改写；派生结果能找到输入、方法、参数与版本。
- 导出再导入保留稳定 ID、时间语义、单位、坐标、模式／安装标签、缺测标记和关联；失败报告指出字段和原因。
- 不支持的 schema 版本、损坏文件、缺单位、重复标识等情况显式处理；容量上限由第一版目标设备决定。
- 位置／轨迹默认本地，不经未授权上传；公开样例必须使用合成或适当去标识的数据。

## D. 仿真与实测比较

- 虚拟手机的安装位置、朝向、重力处理与实物一致；包含必要的刚体转动影响。
- 同一时间窗与滤波定义下比较时域响应、RMS／峰值、频谱与衰减等候选指标；没有人体模型时不能直接给出“晕车改善百分比”。
- 明确路面已知还是未知；拟合报告给出假设、参数限制、误差与可能多解。使用独立记录／工况验证，不把训练样本拟合好等同于真实参数准确。
- 模式比较尽量控制路线、速度、载荷、胎压和安装差异；正常驾驶数据存在的混杂因素必须记录。

## E. 展示与扩展范围

- 替换外观资产、改变渲染帧率不应改变固定物理配置下的数值结果；记录引擎／平台版本，不提前承诺跨平台逐比特一致。
- 车轮、车身和图表使用同一实验状态与时间轴，避免视觉动画假装物理输出。
- 资产纳入交付前记录来源、车型匹配、许可、署名与分发条件；没有许可结论不发布。
- 没有账号时仍能完成已确认的本地流程；预留账号 Interface 不引入登录门槛。

## 测试证据最低内容

每次验证记录日期、环境／软件版本、配置／输入来源、命令或操作、预设判据、实际结果和证据文件。分别标记通过、失败、未运行或受阻；所有尚未定值的判据在此保留为待确认，不因一次演示顺眼而放宽。
