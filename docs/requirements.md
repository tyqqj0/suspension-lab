# 目标、已确认需求与范围

基线日期：2026-10-14。来源为用户讨论及本轮建工作区指示；具体实现仍需按 [未决问题](roadmap.md) 逐项确认。

## 研究使用背景

- 目标车型：方程豹钛3闪充四驱，关注不同悬架模式的车辆响应；不能据车型或配置名推断硬件与控制律。
- 关注场景：起伏路面的车身收敛与低速过减速带的冲击感。主观感受只能提供实验动机，不能作为辨识或控制实验结论。
- 本项目不提供自动车辆模式切换或普适速度阈值。公开材料不保留个人购车与驾驶策略记录。

## 已授权的本轮交付

- 创建工作区、编写项目规则与需求／设计文档、整理现有调研并保持单一可维护来源。
- 核实本地路径和既有规则，做文件与文档链接自检。
- 2026-10-14 用户明确要求“初始化一下仓库先，然后推 github，可以公有，然后再配置 beads 一口气完成”：本轮授权本地 Git 初始化／提交、创建并推送公开 GitHub 仓库、初始化与配置 Beads。发布范围包括本项目工作库；以新的隔离副本检查 clone／bootstrap 恢复，属于本轮交付自检，不启动产品执行器。
- 公开发布限项目文档、必要配置与本项目工作上下文；原始数据、私人记录、本机专用路径和密钥不发布。
- 本轮不编写应用、不安装或升级工具、不采集实车数据、不购买或下载车模、不部署应用，不改共享技能或全局配置。

## 尚未确认的第一版取舍

技术栈、手机平台、后台采集的实现与验收、指定路线与速度或自由驾驶、首版运行方式与功能取舍、七自由度模型、第一版外观降级方案，均不可由本文件推断为定案。切导航采集的分阶段取舍见 C2；不等于已决定延期，也不等于后台能力已经可用。账号仅留接口不意味着需先建一套空账号架构。

## 真实性约束

本项目当前没有经核实的钛3完整悬架参数／控制律，也没有经许可确认的钛3外观资产；只能按现有证据标注模型精度与适用范围。详细证据和检索限制见 [调研笔记](research/tai3-models-and-platform-feasibility.md)；未找到不代表不存在。

## 后续确认方式

用户确认新的范围后，在本文件修改明确条目并注明日期与原因，更新 `roadmap.md` 中受影响的设计依据。Beads 启用后，相关工作的状态、下一步与阻塞仅更新在 Beads；不能因需求确认就关闭包含实现与验收的工作。工程推论保留在 `design.md`，外部事实保留在调研材料，不混入确认表。
