- 项目位置：本仓库根目录，工作名 `suspension-lab`；[公开仓库](https://github.com/tyqqj0/suspension-lab)。

## 目标与非目标

完成公开 GitHub 仓库、项目本地 Beads 和可恢复的工作上下文。Beads 管任务、状态、责任、依赖、停点与下一步；文档管目标、方案、依据和固定验收。

不写应用，不采集实车数据，不选定技术栈，不安装或升级工具，不部署服务，不修改共享技能、全局 Agent 设置或个人任务库。新副本接入测试不等于独立执行器已理解并接手产品工作。

## 固定验收

以下条件沿用 r2，不因执行结果降低要求。

1. GitHub 仓库可公开访问；远端 `main` 与本地提交一致，没有覆盖既有远端历史。
2. 所有普通 Git 跟踪文件均经过公开范围检查；无私有原始数据、密钥、本机专用路径、未授权模型或活数据库文件。仓库提交使用 GitHub 隐私邮箱。
3. 本项目有可用 Beads 1.3.0 数据库；跳过 hooks／agents 自动生成，核验初始化实际改变的文件和提交。创建前查重、写后回读，得到真实工作编号。
4. 第一批工作只覆盖已明确的目标与近期设计收敛；状态和下一步仅在 Beads。切导航采集遵循需求 C2，不能提前宣称后台能力可用。
5. Beads 远端使用同仓库专用数据引用；发布后确认其存在，不能把退出 0 的 skipping 当成功。普通文件与工作库分别交付。
6. 在全新独立目录 clone 普通文件并 bootstrap Beads；回读相同编号、标题、notes、文档修订与提交引用。不得复制运行数据库或以重新 init 冒充恢复；新副本不领取、不修改业务任务。
7. 文档链接有效、原调研 SHA256 不变，原始数据忽略规则有效。检查证据区分通过、失败、未运行与受阻。
8. 独立 Agent 语义理解／执行验收另行开展；本轮发送端、文件审阅或新副本传输核验不冒充这项验收。

## 依据与决定

### 用户确认

- 产品目标与工作管理方式见 [需求](../../docs/requirements.md) C1–C7。
- 2026-10-14 用户明确要求“初始化一下仓库先，然后推 github，可以公有，然后再配置 beads 一口气完成”。本轮按此完成仓库、公开发布与 Beads 接入；新副本恢复检查是交付自检，不启动产品执行器。
- 手机切导航后持续记录：可顺利完成则首版做，困难可后补；锁屏、设备、质量判据与平台未定。

### 事实与建议

- 本机既有 `bd` 为 1.3.0（f45b249ce），可复用，无需本轮安装。具体工具路径属于本地环境信息，不写入公开仓库。
- 本项目从空 Git 历史和无 `.beads` 开始；不复用其他试验项目的业务数据库。初始化自动产生 Git 提交；本轮不重做初始化或重写历史。
- 调研原文 SHA256：`0a7719eebc98e97a2f828d205ea0cf83616815ee71aae0a477dabc78e25b9a8f`。研究页面反映 2026-10-14 的证据与限制，不是长期能力保证。
- 首批工作覆盖总目标、仓库接入、手机验证范围、首版闭环范围。P2 是工具默认值，不表示用户裁定相对优先级；父子归属不是阻断依赖。

### 未决与暂停边界

目标手机、锁屏要求、首版实验方式、栈、可接受验证成本与具体性能阈值未确认，影响对应实现。公开授权不扩大为应用开发、路测、购买资产或部署授权。遇到远端历史冲突、凭据不可用或数据接入失败时停止受影响发布，不强制覆盖或降级为文件任务库。

## 执行与接续

先读项目规则、需求和阶段门槛，再读取对应 Beads 工作项；不要根据本文的工作名称推断当前状态。新副本按 [Beads 使用入口](../../.beads/README.md) 接入已发布历史；已有工作区不重新初始化。

按 `work-handoff` 技能交付：先文档，后指向它的 Beads 状态；接收方核对两个通道。不在普通 Git 历史存储活数据库或把 `refs/dolt/data` 合并进 `main`。专用数据引用不是隐私隔离，本项目整个工作库都必须适合公开。

执行中的停点、阻塞与下一步以工作库为唯一权威来源。没有 Beads 工具或库无法读取时报告缺口，不猜进度、不重新创建任务。单活跃写入者；测试副本只验证传输，不领取任务。
